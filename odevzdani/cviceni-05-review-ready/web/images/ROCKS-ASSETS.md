# Prague Rocks Festival visual assets

- `prague-rocks-logo.svg` and `prague-rocks-logo-light.svg`: original outlined wordmarks composed specifically for this fictional festival. Letter outlines come from the project's self-hosted Barlow Condensed 900 (SIL Open Font License 1.1; full license in `fonts/`). The lettering arrangement, lightning accent and underline are original. No Rock for People logo, font file or artwork was copied.
- `rocks-mark.svg`: original geometric music/lighting illustration created for the site.
- `festival-atmosphere.webm`: silent 10-second 1280 × 720 VP9 animation, 24 frames per second, made with FFmpeg from this project's existing original AI-generated `festival-crowd.png`. Slow, seamless panning and zooming animate a still image. It is illustrative animation, not filmed festival footage or an accurate representation of the real Výstaviště site. Original image provenance is in `ASSETS.md`.

The hero uses a local image poster and local video file. It pauses on request and does not start automatically when the browser requests reduced motion. No external video player, stream, tracker or CDN is used. Performer image provenance is documented separately in `performers/README.md`.
