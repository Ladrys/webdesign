# Interaktivní wireframe — Prague Pulse Fest

Otevřete `index.html` v prohlížeči. Bez instalace, serveru a buildu.
Prototyp používá přibalená data `data.js`; JavaScript musí být povolen.

Wireframe slouží k ověření obsahu, navigace a dvou hlavních cest návštěvníka.

S1: Program → den → scéna → uložit akci → Jen uložené → obnovení.
S2: Vyhledávání DARKZY → DARKZY → detail → Program interpreta.

Podporuje filtry, osobní program, hledání části textu a detail interpreta.
Celý nákup a účet obsahuje hotový web ve složce `web/`.
