# Cross-review — šablona k doplnění

**Autoři podkladu:** Michal Ladra, Matěj Mlejnek, Jan Martínek.

**Nejde o dokončené hodnocení.** Přidělený cizí projekt ani jeho specifikace
nebyly dodány. Před odevzdáním nahraďte prázdná pole skutečnými údaji,
proveďte obě metody a doplňte ověřené nálezy. Stejně upravte prezentaci 06.

## 2. Metoda: Nielsenovy heuristiky

Nejprve projděte web jednotlivě, potom sjednoťte duplicitní zjištění.
U každého nálezu určete konkrétní pravidlo: viditelnost stavu; shoda
s reálným světem; kontrola uživatele; konzistence; prevence chyb; rozpoznání
místo vybavování; efektivita; přiměřený minimalismus; pomoc při chybě;
nápověda. Pouhé „nelíbí se nám barva“ není heuristický nález.

Zdroj metody: Nielsen Norman Group,
[10 Usability Heuristics for User Interface Design](https://www.nngroup.com/articles/ten-usability-heuristics/).

## 3. Metoda: kognitivní průchod

Oba scénáře rozdělte na jednotlivé kroky. U každého odpovězte:

1. Bude uživatel vědět, čeho chce dosáhnout?
2. Všimne si správného ovládacího prvku?
3. Spojí si dostupnou akci se svým cílem?
4. Pozná po akci, že postoupil správně?

Zaznamenejte překážku, důkaz i případnou náhradní cestu. Kontrolujte mobilní
zobrazení, klávesnici a prázdné či chybové stavy. Expertní průchod není
experiment s reprezentativním vzorkem uživatelů.

## 4. Závažnost

| Závažnost | Dopad |
| --- | --- |
| Kritický | Blokuje klíčový cíl bez rozumné náhradní cesty |
| Významný | Zásadně komplikuje cestu, vyvolává chyby nebo nejistotu |
| Drobný | Místní problém čitelnosti či konzistence; cíl zůstává dosažitelný |

Ke každému nálezu připojte screenshot s kontextem nebo jiný reprodukovatelný

výpovědi testerů. Pro prezentaci vyberte **3–5 nejdůležitějších skutečných
nálezů**, které lze vysvětlit do pěti minut.
